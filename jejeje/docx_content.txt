12. Recomendación técnica de frontend
Organización por features: auth, profile, dashboard, tenants, users, audit, sessions y system.
Server state: TanStack Query (o equivalente) para listados, detalles, dashboards, auditoría y sesiones.
Estado global ligero: store para auth/session meta, current user summary y flags UI.
Formularios: react-hook-form + esquema de validación (zod/yup o equivalente).
Cliente HTTP único con interceptores: attach token, refresh, normalización de errores y redirección controlada.
Invalidación de caché tras mutation: listas, detalle relacionado y dashboard si cambia el dato mostrado.
Limpieza de sesión: logout o invalidate → limpiar auth store, query cache y cualquier dato tenant-scoped.
