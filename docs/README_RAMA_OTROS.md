# Rama `otros`

Esta rama contiene el monorepo **sin** la carpeta `jejeje/` (el stack Express + Vite del producto principal).

Incluye:

- `backend/` — API Spring Boot + `docker-compose` de Postgres en la raíz.
- `frontend/` y `backend/frontend/` — apps Angular.
- `n8n-number-processor/` — Angular 17 y workflows n8n de ejemplo.
- `docs/` y `README.md` de la raíz.

El código completo, incluido `jejeje/`, está en la rama **`main`**.
